# pubglobalupdate.dart

Workspace for the `pubglobalupdate` command, see
[packages/pubglobalupdate](packages/pubglobalupdate/README.md).

* `packages/pubglobalupdate`: the published package (`dart pub global activate pubglobalupdate`)
* `example/packages/tkhello`: hello world CLI with launch diagnostics, not published
  (test subject of the `dart install` versus `dart pub global activate` experiment)
* `example/packages/tkhellohooks`: the same with a build hook dependency (sqlite3)
